## Entry

yawncatch (n.) — a yawn you catch from watching someone else yawn.

## Why this word

English has a phrase for it — "contagious yawning" — but no single word you can actually use mid-conversation. *Yawncatch* fills that gap with two plain parts anyone can say and spell on first hearing: *yawn* + *catch*. The definition lands in one reading, names a moment every reader has lived, and the word itself is short enough to stick. Judge it against the brief: a real gap, a one-line definition that needs no second pass, and a coinage that is sayable, spellable and memorable.

## Verification

Run with Node 22 (stdlib only):

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts
cat output/entry.txt
```

`main.ts` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`, validates the bounty gate (single lowercase coined word; one-line definition of at most 140 characters; exactly one line), then reads the file back and verifies it byte-for-byte before logging the result.
